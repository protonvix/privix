# Vix Studio · Websites by Promise Felix

Static site (no build step), deployed on Cloudflare Pages at https://vixautomationsportfolio.pages.dev.

- `index.html`, `styles.css`, `app.js`: the page, the 10-design gallery and the 6-step brief builder.
- `scene.js`: the interactive 3D showcase (Three.js, loaded from unpkg): a car with paint colours and a house with day and night.
- `assets/designs/`: previews for the 10 designs. `assets/work/`: project screenshots. `assets/3d/`: the car model (Ferrari 458 by vicent091036 on Sketchfab, from the three.js examples).
- Briefs are emailed to vixautomations@gmail.com through FormSubmit and open in WhatsApp (UK +44 7723 149573) with the brief already filled in. Contact settings are at the top of `app.js`.

Cloudflare Pages settings: no build command, output directory `/`.
