# Promise Felix · Portfolio

Static portfolio site (no build step), deployed on Cloudflare Pages at https://vixautomationsportfolio.pages.dev.

- `index.html`, `styles.css`, `app.js`: the portfolio. Contact links, WhatsApp numbers and project links live in `CONFIG` at the top of `app.js`.
- `famous-automobile/`: the Famous Automobile website shown in the portfolio.
- The Vix Automations project links to the live site at https://vixautomations.pages.dev.

Cloudflare Pages settings: no build command, output directory `/`.
